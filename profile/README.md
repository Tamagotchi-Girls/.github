## 👾 ¿Quiénes somos?

> **`Sobre nosotras.txt`**
>
> Tamagotchi Girls es una organización estudiantil creada para conectar chicas interesadas en tecnología, diseño y hardware.
>
> Queremos crear un espacio donde podamos aprender juntas, colaborar en proyectos reales y convertir nuestras ideas en tecnología.

```diff
> mision.exe
> CARGANDO: MISSION...
> STATUS: ACTIVA ✓

+ Aprender haciendo proyectos reales.
+ Conectar diseño, código y hardware.
+ Construir una comunidad inclusiva.
+ Crear tecnología con identidad propia.
```
